Stylish Name Maker Bot - V6

Features:
- Stylish Name Maker with Premium / Aesthetic / Live / Bangla Live sections
- 10 styles per page with pagination
- BIO Maker
- Bulk Name Maker
- Direct handler registration (no plugins folder required)

Environment variables for Render:
BOT_TOKEN=your_bot_token
API_ID=your_api_id
API_HASH=your_api_hash
OWNER_ID=your_telegram_user_id
PYTHON_VERSION=3.11.9

Run:
python bot.py
